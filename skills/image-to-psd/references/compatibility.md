# PSD 兼容性排查

1. 查看问题截图；尽可能确定软件和导入方式。不要反复要求确认常规修复。
2. 保留故障文件，与能正常打开的 PSD 对照：尺寸、8 位 RGB、图层顺序、大小、偏移、可见性、透明通道、独立蒙版与坐标。蒙版差异只是候选原因。
3. 使用全画布 RGBA 部件与同尺寸独立覆盖蒙版。全画布注册不等于全画布不透明，alpha 必须是当前部件自身形状。
4. 使用 RLE 普通像素层，避免无必要的智能对象、嵌套组、混合模式、数字前缀、全局蒙版。默认保留标准 19 层。可选的手与道具交错布局为 20 层。目标工具要求固定层结构时按其要求制作兼容版。
5. 重新读取每层的 alpha、mask、bounds 和 name。整图预览正常不代表独立图层正确；拒绝把同一张不透明原画写入每层。
6. 重要修复使用第二种独立解析器。Node ag-psd 需要 initializeCanvas 和 ImageData，并设置 throwForMissingFeatures: true；防止静默解码失败被误当空层。核对各层 imageData 和 mask.imageData 的尺寸、非零像素，必要时独立合成。
7. 仅实际在用户目标工具导入并观察正常后声明目标软件已验证，否则说需要重新导入确认。

默认将软透明度保留在像素 alpha 中，独立蒙版只标记覆盖范围。重读后检查蒙版与 alpha 的画布位置一致，且合成有效 alpha 与输入一致。目标软件有明确的通道要求时按其规范调整，并用抗锯齿与半透明样本复查导入效果。
