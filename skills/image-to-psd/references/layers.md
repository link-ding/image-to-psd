# 标准部件

使用下列 19 个名称，不加数字前缀，不按左右另建顶层。表格顺序不代表固定绘制顺序；按当前原画遮挡关系排序。

| 名称 | 归属 |
|---|---|
| back hair | 后发；补被头遮住的连贯形状 |
| front hair | 前发、刘海及需要随前发运动的侧发 |
| face | 连续脸部底形、腮红；补刘海及五官下方区域 |
| ears | 人耳或猫耳；可见部分独立，补必要连接处 |
| earwear | 耳饰；头发蝴蝶结不放这里 |
| eyebrow | 左右眉毛同层，排除肤色及头发碎片 |
| eyewhite | 左右眼白同层；瞳孔移走后仍完整 |
| irides | 左右虹膜、瞳孔及其高光同层，排除睫毛 |
| eyelash | 左右睫毛、眼线同层，区分上下眼线 |
| nose | 仅鼻子，保留微小笔触 |
| mouth | 原画嘴型；避免携带矩形肤色贴片 |
| headwear | 发花、发卡、帽子、头部蝴蝶结及飘带 |
| neck | 脖子；补脸和衣领下方必要部分 |
| topwear | 上衣、上半身及胸花、领结等衣服装饰 |
| handwear | 手、手臂、袖子、手套合一层，不承诺单独动手 |
| bottomwear | 可见裙子、裤子；不把上衣下摆强行当完整下装 |
| legwear | 腿与袜子；未入画留空 |
| footwear | 鞋；未入画留空 |
| objects | 手持书本、道具；保留与手的正确遮挡 |

## 手与道具交错的可选布局

手和道具需要独立移动、且道具同时遮住一部分手又被另一部分手压住时，用 `handwear back` 和 `handwear front` 取代 `handwear`。两层分别放在 `objects` 后方与前方，PSD 按该顺序导出，共 20 层。沿原画的共同接触线分配可见像素，只补移动时会露出的遮挡区。两层随同一手部动作移动。交付时说明此布局，并在目标工具要求严格 19 层时提供按原位效果合并的兼容输出，核对合并后的手与道具遮挡。

## 检查要点

- 将推补形状放在对应图层底部，避免巨大跨部件遮罩。
- 眼白覆盖虹膜移动范围；下游负责裁剪时不要重复施加静态坐标裁剪。
- 默认合并袖子和手时，按原画保留书与手指各自可见的范围。
- 保留原画可见区域的手绘笔触，重点复查半透明边缘与补画接缝。
- 放大检查白边、拼缝、锯齿、漂浮碎片，不能仅看缩略图。
- 单独请求五元音时才制作嘴型，保持共同锚点，不覆盖默认原画 mouth。
