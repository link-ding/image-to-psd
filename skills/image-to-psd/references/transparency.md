# 浅色部件与透明度检查

## 分离背景

- 把颜色和透明度分别处理。白色衣服、袖子、浅发、眼白、高光、翅膀内的白色均可能是实体，不能因其颜色接近纸白就令 alpha 为零。
- 先确定部件轮廓与语义归属，再去除轮廓外背景。颜色阈值、从画布边缘漫水填充及闭运算只能提供候选背景；松散手绘线条的缺口会让填充侵入衣服内部，不能直接接受结果。
- 对有实色材质的部件，在本层底部建立贴合轮廓的连续底形，上方保留原线稿、阴影和纹理。PSD 从同坐标的透明部件 PNG 直接导出，令内部 alpha 与蒙版保持实心。不要用全画布白色矩形补救。
- 根据原图区分真实镂空、头发之间的空隙、蕾丝和半透明材质；不要把所有封闭区域或所有低 alpha 区域一律填满。新增遮挡底形注明为推补；保留原本就可见的白色材质属于恢复实体。

## 导出验收

1. 重新读取 PSD 后，生成透明棋盘格和深色背景预览；检查完整合成，并单独检查 topwear、handwear、浅色头发、eyewhite 及其他浅色部件。白底会掩盖镂空，不能作为唯一验收依据。
2. 按当前图的语义选择应为不透明材质的内部点，避开边缘和实际镂空。上衣胸腹、两侧袖子、浅发主体分别取点，检查本层像素 alpha 与独立蒙版：实色内部应为 255；若明显降低或为零，追查分割与底形。真正半透明材质按原图另判。不要复用其他角色的绝对坐标。
3. 比较单层覆盖范围与原图轮廓：不能只剩衣服装饰、黑色描线、阴影或零散高光，主体却透明。检查胸腹、袖口、衣领接缝和画面下缘，不要仅抽查一个中心点。
4. 修复后重新导出 PSD，重读 alpha 与蒙版，并复查两种背景。不得只改合成预览或加总背景层；背景层会掩盖拆层错误。

典型失败：浅紫龙角角色在白底预览中衣服看似正常，切到透明棋盘格后胸腹和袖子仅剩笔触。把此类结果视为分割失败，即使层数、命名、蒙版存在性及 PSD 合成一致性检查全部通过，也必须修复。
