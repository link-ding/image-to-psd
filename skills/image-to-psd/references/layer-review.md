# PSD 逐层审核与补画

## 部件参考图与混合拆层

1. 用原画作为 ImageGen 参考，要求一张可逐件裁切的透明底图，按 19 个标准英文层名独立摆放部件，标注与部件之间留足间距。保留原画姿势、表情、颜色、笔触和构图，只补必要的遮挡轮廓。未入画的部件只留空位。白色眼白、袖口和头饰等实体须保持实心。
2. 导出前对照原画审核参考图。逐项核对归属、可见轮廓、角度、手指和发束。挑出能用于补形的片段，把有串层、偏色、姿势偏移或边缘残影的片段排除。生成部件不合格时保留原画的可见内容，按需重画局部或用原形延伸。
3. 用原画作可见部位的像素和轮廓来源。将选中的生成片段按原图锚点缩放、旋转并对齐，用独立蒙版限定补形范围。默认避免整件替换。只有原画无法可靠提取、生成件复核后贴合原画，或用户明确要求用生成图直接组装时，才采用整件替换。
4. 在部件源中记录哪些区域来自原画、哪些经过生成补形。先检查原位合成和拆开的单层，再导出 PSD 初稿并按下文复查。

## 共同划分可见边界

- 在同一个原画坐标下放大相邻部件，先画一次接触边界并标注可见像素和共用线稿的归属，再从这份标注生成相关蒙版。手指压在书上时沿实际指缝和书脊切分。浅色发饰贴着浅发时沿连续线稿和结构判断。
- 在原位合成中检查半透明边缘有无双描、漏缝或背景色污染。把需要在动作中露出的下层补形放在可见边界下方，另行记录补形范围，以便对照原画时区分原有像素和推补区域。

## 交付前自查清单

检查**实际要交付的版本**。以重新读取的 PSD 为准，保留内部预览并记录每项通过、待修复或不适用。只有在部件确实不存在时才记不适用。

| 检查项 | 通过标准 |
|---|---|
| 文件结构 | 核对画布尺寸、图层名称与顺序、坐标、有效透明度和 PSD 独立蒙版。对照原画确认空层对应未入画的部件。 |
| 原位合成 | 在透明棋盘格和深色底上查看整图；对照原画确认表情、轮廓和位置。对眼睛、头饰、手与道具、后发等高风险交界，在可比较的区域以同一背景制作同坐标局部差异图，检查缺笔、色边和重复轮廓。 |
| 逐层隔离 | 查看每个非空层，PSD 按独立蒙版生效后的结果检查。核对部件归属和边缘完整性；确认浅色实体内部仍有正确覆盖，背景已去除。 |
| 关闭遮挡与位移 | 移开刘海或脸检查后发，移动手或道具检查被遮住的接缝。有虹膜时执行[眼部专项验收](#眼部专项验收)。在预期的小幅动作内，新露出的区域应连续，无残影、透明洞或重复碎片。 |

发现问题后，比较部件源与重新读取的 PSD，区分源部件缺陷与 PSD 导出问题。确定像素归属和修复范围，修复后重导出，再检查失败项、相邻层和原位合成。格式问题在对应的导出环节修正。能修复的问题要在交付前处理；确实无法验证或修复的项目说明具体位置和限制。

| 初稿问题 | 处理方式 |
|---|---|
| 多出轮廓、串层、漂浮碎片 | 对照原画收紧该层蒙版，把确属其他部件且尚未保留的像素归回对应层。 |
| 原画可见内容被裁掉 | 从原画取回原像素和笔触。若原图边界复杂且无法可靠提取，可用 ImageGen 修补小段，再按原画复核。 |
| 遮挡下缺形，或补形过宽、颜色平板、发束断裂 | 缩小到实际需要的遮挡范围。形状明确的短接缝用原形延伸，复杂轮廓或纹理用 ImageGen 局部补画。 |
| 部件源正常但 PSD 预览异常 | 查像素透明度、蒙版和偏移，在对应步骤修复后重新导出。 |

- **handwear** 包含原画对应的手、手臂、袖子和手套。分侧核对手指数、手掌和手腕轮廓、袖口以及手与道具的遮挡。清理多出来的手形、跨到别处的笔触和归属其他层的碎片。只补实际需要的手腕或袖口连接处。
- **headwear** 在有色背景上单独检查头饰两端、白色荷叶边及蝴蝶结周围。确认原画中的白色实体完整，发饰边缘没有误带头发。
- **back hair** 对照原画确认后发、前发、耳朵及发饰边界。检查发束走向、发尾和头部遮挡下的连接。可见发束延用原画轮廓和笔触。移开脸或前发，确认需要露出的后发连贯，既无断层，也无伸出头部的生硬色块。

## 眼部专项验收

1. 在原画坐标放大左右眼，分别画一份完整眼裂轮廓，包含睫毛遮住的窄边。以这份轮廓共同划分眼白、虹膜、眼线及刘海交界。将虹膜、瞳孔、眼内高光和抗锯齿边缘完整归到 `irides`。蓝发贴眼时同时查形状与连通性，避免用蓝色阈值单独判断归属。
2. 在整个眼裂内补出连续眼白。保留确认干净的可见眼白，按同一只眼的颜色与上睑阴影补画虹膜原来盖住的范围。排除虹膜和高光外缘的混色带，再用平滑的同色阴影连接；原虹膜移开后的区域应有完整不透明底色。明显残影时重建整块眼白底色。
3. 在初稿和每次修复后，分别查看眼白单层、隐藏 `irides` 的原位合成，以及虹膜向两侧小幅位移的合成。在静止位置对照原画确认虹膜与高光完整。关掉虹膜后仍有色块时，逐个关掉 `front hair`、`eyelash`、`eyewhite` 和 `face` 定位残留，并把误收的虹膜像素归回 `irides`。仅在原位叠得正确也须做这三项检查。
4. 位移验收时用眼裂范围预览裁剪，确保移动后只出现一对虹膜，原位置无深色弧线、反光残点或透明孔。裁剪边界固定在眼裂，随眼白或眼框一起移动。目标工具已有动态裁剪时，交付保留可独立移动的虹膜像素。

## 用 ImageGen 局部补画

1. 每次聚焦一个部件的一个缺陷。把原画局部作为造型、颜色和笔触参考，把当前单层作为编辑目标。保留足够的周边线索对齐锚点，例如袖口两端或发束交界。明确需要补画的区域、应保留的可见轮廓、大小、角度及与相邻部件的接缝。请求真正透明的背景。
2. 把生成图当作候选。检查手指、发束、颜色、线条、透明边缘和尺度。对齐原画画布，只接纳缺损范围内的有效补画，用蒙版限制替换范围，保留范围外原像素与原图层坐标。生成结果偏离原画时做一次针对性重试，仍不合格则保留最忠实的局部修复并说明剩余缺陷。
3. 用确认过的部件源更新 PSD 像素及独立蒙版，再重新导出。重读 PSD 检查层名、顺序、位置和独立蒙版，再核对单层、原位合成与小幅位移。确认拼接处在恢复原位后贴合原画，移动后也有足够覆盖。
